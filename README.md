# 🌐 Website Sekolah - Template Astro

Proyek ini adalah **template website sekolah** yang dibuat menggunakan [Astro](https://astro.build/), dengan dukungan **Tailwind CSS** untuk styling dan **Splide.js** untuk komponen slider yang ringan dan responsif.

## 🚀 Teknologi yang Digunakan

- [Astro](https://astro.build/): Framework modern untuk membuat website statis yang cepat.
- [Tailwind CSS](https://tailwindcss.com/): Utility-first CSS framework untuk styling yang fleksibel dan efisien.
- [Splide.js](https://splidejs.com/): Slider/carousel ringan dan kaya fitur.
